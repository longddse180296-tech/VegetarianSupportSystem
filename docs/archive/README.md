# Báo cáo lịch sử

Các báo cáo trong thư mục này ghi trạng thái ở thời điểm thực hiện, có thể chứa kế hoạch hoặc chức năng đã được thay thế. Dùng README tại gốc, STRUCTURE.md, docs/mvp.md và contracts làm nguồn hướng dẫn hiện tại. Các báo cáo được giữ để đối chiếu quá trình làm việc và bảo vệ dự án; không chạy các lệnh seed cũ lên database đang demo.
